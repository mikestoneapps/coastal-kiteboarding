# Coastal Kiteboarding

**Bistué Boarding** — where to kite today: the Columbia Gorge or the Oregon coast, scored 0–10 and ranked by drive time.

Live: https://mikestoneapps.github.io/coastal-kiteboarding/
On an iPhone: open the link in Safari → Share → **Add to Home Screen**.

- Forecasts: Open-Meteo, five models in one call (best match, ECMWF, NBM, GFS, ICON) + marine model, fetched on every open. The score runs on the hourly median of best match, ECMWF and NBM; all five vote on confidence. Knots by default, mph under Rider.
- Live wind: nearest NWS/METAR stations, with distance; NOAA buoys via the hourly job (phase 1).
- Scoring, spot rules, alerts and roadmap: see `SPEC.md` and `docs/BUILD-PLAN.md`.
- For Claude Code: read `CLAUDE.md` first.
